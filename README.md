# Taktvoll – Prototyp

Erster mobile-first Prototyp für ein digitales Klassenbuch österreichischer Musikschullehrer.

## Enthalten
- Tagesansicht nach Musikschule
- mehrere Schulen / Bundesländer
- schnelle Unterrichtsdokumentation
- Status: gehalten / nicht gehalten / verschoben
- Diktierfunktion (wenn Browser unterstützt)
- Schülerübersicht
- Bibliothekskonzept inkl. Papier/PDF
- Audio-Player-Konzept mit Tempo / Halbton / QR
- Ensemble-Anwesenheit
- Jahresdokumentation-Konzept
- optionales Hausübungsfeld, nicht Teil des Jahresexports

## Start
Die Datei `index.html` in einem Browser öffnen. Für iPhone-Tests ist später ein kleiner Webserver/Deployment sinnvoll.


## Arbeitsmarke
Taktvoll – Das digitale Klassenbuch für Musikschulen.
